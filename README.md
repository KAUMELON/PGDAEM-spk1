# Decision Making and Problem Solving in Extension Organisations

Online course book for **Decision Making and Problem Solving in Extension Organisations**, Post Graduate Diploma in Agricultural Extension Management (PGDAEM), Central Training Institute, Mannuthy, Kerala Agricultural University.

Based on the course notes of Smija P K, Assistant Professor (Agricultural Extension Education), Central Training Institute, Mannuthy.

Built with [Quarto](https://quarto.org/). The rendered site is in `docs/` and is served by GitHub Pages at <https://kaumelon.github.io/pgdaem-spk1/>.

```
quarto render
```
